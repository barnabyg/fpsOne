# Use Unreal Engine 5.8

Use Unreal Engine 5.8 for the first-person testbed because achieving the required environment and humanoid fidelity in a very small playable area matters more than using an open-source engine. The testbed is personal and non-commercial, so Unreal's zero-cost licensed workflow is acceptable even though the engine is proprietary and source-available rather than open source.

## Considered Options

Godot with Blender and openly licensed assets would provide a fully open-source toolchain, but would demand substantially more custom rendering and content work to reach the visual target. Unreal provides the more direct high-fidelity path through its renderer and asset ecosystem.

## Consequences

Development requires Epic Games Launcher, Unreal Engine 5.8, Epic account authentication, and acceptance of Epic's licenses. Third-party assets must be individually licensed for this personal project, and their source files must not be published when their licenses prohibit standalone redistribution.
